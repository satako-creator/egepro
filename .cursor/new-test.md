**ПРОМТ ДЛЯ ГЕНЕРАЦИИ ТЕСТОВ (practice-questions)**

У меня проект на Payload CMS. Есть коллекция `practice-questions`, поле `question` и `options` — это Lexical richText с поддержкой:

- заголовков (h1–h4),
- параграфов,
- списков,
- ссылок,
- формул через кастомный блок `equationBlock` (LaTeX‑строка + подпись).

Вопросы сидятся отдельным скриптом, который ожидает от тебя **структурированное описание** каждого теста, без заботы о JSON Lexical — JSON собираю я через свои хелперы.

Текущий контекст:

- Предмет: Математика.
- Конкретный урок: «Логарифмы: определение и свойства», `lessonSlug = "logarithms-definition-properties"`.
- Коллекция: `practice-questions`.
- Типы вопросов:
  - `single` — один правильный вариант ответа;
  - `multiple` — несколько правильных вариантов;
  - `numeric` — ответ числом или выражением (строкой);
  - `formula` — ответ формулой (мы храним как текст, но показываем как LaTeX).
- Для каждого вопроса уже есть поля:
  - `type`
  - `difficulty` (`easy` | `medium` | `hard`)
  - `order` (порядок в уроке)
  - `points`
  - `timeLimit` (сейчас всё равно 0 = без ограничения)
  - `tags` (просто массив строк)

Что от тебя нужно выдать:

Сгенерируй массив вопросов по логарифмам **в формате чистых данных**, без кода, примерно так:


Пояснения к полям:

- `questionTitle` — краткий заголовок (для превью и h3 в вопросе).
- `questionText` — основной текст вопроса (параграф).
- `questionFormula` — если в самом вопросе есть одна ключевая формула (мы её отрисуем отдельным EquationBlock).
- `options` — **только** для `single`/`multiple`:
  - `text` — текст варианта (мы сделаем richText-параграф);
  - `isCorrect` — пометь истинные варианты.
- `correctNumericAnswer` — только для `numeric` (строка, как в ЕГЭ).
- `hintText` — текст подсказки (мы сделаем 1–2 параграфа).
- `hintFormula` — одна формула в подсказке (EquationBlock).
- `explanationText` — текст объяснения (параграф/параграфы).
- `explanationFormulas` — массив формул LaTeX, которые нужно показать в разборе как отдельные блоки.

Требования по содержанию:

1. Тематика вопросов — строго по уроку «Логарифмы: определение и свойства»:
   - определение логарифма,
   - базовые свойства (лог 1, лог основания, произведение/частное, степень/корень),
   - переход к новому основанию,
   - частные случаи (lg, ln),
   - простейшие логарифмические уравнения/неравенства на уровне ЕГЭ.
2. Количество вопросов: 5.
   - 1 лёгкий `single` (определение/базовые свойства),
   - 2 средних (`single` или `numeric`) на применение свойств/переход к основанию,
   - 2 посложнее (`numeric` или `single`) на простые уравнения/неравенства ЕГЭ‑стиля.
3. Ответы должны быть однозначными, без спорных формулировок.
4. Формулы — корректный LaTeX (для логарифмов: `\\log_a b`, `\\ln x`, `\\lg x`, степени `a^x`, дроби `\\frac{}`, корни `\\sqrt[n]{x}`).
5. Не пиши код, JSON мне нужен только как структура данных — я сам интегрирую в сид.
